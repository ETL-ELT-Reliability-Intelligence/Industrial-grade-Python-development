# Просмотр трёх оформлений

Оставлены **Windows XP / Classic**, **CS 1.6**, **Design Wizard**. Остальные
концепции и их ресурсы удалены. Статичные дубликаты экранов также удалены:
галерея теперь открывает текущий `services/frontend` с рабочими маршрутами API.

Из корня репозитория, после установки обычных зависимостей приложения:

```powershell
uv run --no-sync python experiments/design-lab/preview.py
```

Адрес: http://127.0.0.1:8010/ . Остановка — Ctrl+C.
Старый запуск через `python -m http.server` больше не подходит.

Этот отдельный процесс использует фиксированный репозиторий в памяти и всегда
показывает плашку тестового просмотра. Он не подключается к PostgreSQL, не
очищает БД и не подставляется автоматически при ошибках основного backend.
Порт 8000 остаётся обычным приложением с `DATABASE_URL`.

## Проверка и скриншоты

```powershell
uv run --no-sync python experiments/design-lab/verify.py
```

Проверяются три варианта в настоящем браузере через API preview-сервера,
переключение тем без потери выбора, пустой датасет, повтор запроса и мобильная
ширина. Скриншоты desktop — 1440×900, mobile — 390×844 с полной высотой.
На Windows используется Edge; можно задать `PLAYWRIGHT_EXECUTABLE_PATH`.

Основные браузерные тесты приложения: `tests/application/test_dashboard.py`.
Интеграция с PostgreSQL подтверждается отдельно, только с `TEST_DATABASE_URL`.

Палитры, URL-параметры, происхождение иллюстрации и поведение тем описаны
в [документации оформления](../../docs/application/themes.md).
