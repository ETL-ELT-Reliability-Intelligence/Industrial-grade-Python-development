Три рабочих варианта

Исходный Windows XP / Classic, серверы CS 1.6 и Design Wizard. Это один актуальный экран приложения с общим API: меняется только оформление.

Здесь используются фиксированные тестовые данные. Можно выбирать датасеты и scope, обновлять экран и переключать оформление. Этот просмотр не подключён к PostgreSQL.

Наш исходный интерфейс: серая панель, синие заголовки, белые таблицы. Используется по умолчанию.

Design Wizard

Классическая программа с небольшим 3D-помощником. Его можно скрыть кнопкой, сохранив выбранные данные.

Открыть →

Что можно попробовать

  1. Открыть вариант и переключить оформление в верхней панели.
  2. Выбрать sample-app-empty — посмотреть пустые состояния.
  3. Вернуться к sample-app-orders и выбрать sample-window-1.
  4. Проверить ноль, отсутствие измерения, UNKNOWN и решение BLOCK.
  5. В Wizard скрыть и вернуть помощника.

Для данных из PostgreSQL используйте обычный backend на порту 8000 с настроенной DATABASE_URL. Три темы доступны и там.
