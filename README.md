# Система мониторинга и анализа надёжности ETL/ELT-пайплайнов

Отслеживает качество данных и состояние их обработки, выявляет отклонения, связывает связанные проблемы в инциденты и помогает определить возможную первопричину и зону влияния.

Со схемами системы можно ознакомиться в разделе [docs](./docs/).

Документация backend/frontend находится отдельно в [docs/application](./docs/application/): [план итераций](./docs/application/plan.md).

## Возможный вариант структура репозитория
```text
./
├── services/
│   ├── ingestion/
│   ├── stream_processor/
│   ├── incident_engine/
│   ├── backend/
│   ├── agent/
│   └── frontend/
│
├── contracts/ # общие модели данных и контракты взаимодействия между компонентами
├── data_quality/ # общая логика проверок качества данных и правил принятия решений
├── pipelines/ # описание пакетной обработки и ELT-процессов
│   ├── airflow/
│   └── dbt/
│
├── database/ # миграции и схема служебной базы данных
├── tests/
├── docs/
├── scripts/ # скрипты для запуска и другие
├── docker-compose.yml
└── pyproject.toml
```
