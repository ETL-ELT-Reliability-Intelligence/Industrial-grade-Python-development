# Три оформления dataset-экрана

В приложении доступны Windows XP / Classic, серверы CS 1.6 и Design Wizard.

## Основное приложение

Все три оформления используют один HTML, JavaScript и настоящий API `/api/v1`.
Выбор датасета и scope, пагинация, обновление, ошибки и безопасный вывод текста
общие. Переключатель «Оформление» меняет тему без запросов к API и без сброса
текущей страницы списка. Исходное оформление Classic используется по умолчанию.

- `/?theme=classic` — исходная серая палитра Windows Classic/XP, синие заголовки.
- `/?theme=cs` — компактные строки каталога и панель свойств в VGUI-палитре.
- `/?theme=wizard` — классическая серая утилита с убираемым персонажем.

`theme` сочетается с `dataset` и `scope` в прямой ссылке. Явная тема из URL
приоритетнее сохранённой в localStorage; неизвестное значение даёт Classic.
Если параметра нет, используется сохранённая тема либо Classic. Выбранная тема
записывается в текущий URL. Если localStorage запрещён, интерфейс продолжает работать.
Кнопка «Помощник» доступна только в Wizard; её состояние сохраняется отдельно.
Подсказка статична и не является Agent/RCA или результатом анализа данных.

## Цвета

Оригинальная тема сохранена: `#D4D0C8`, `#0A246A`, Tahoma и белые таблицы.
Wizard использует `#C0C0C0`, `#000080`, белые таблицы и бирюзовый рабочий стол
`#008080`. Это классическая серая схема, не синяя тема Luna.

Для CS значения взяты из секции Colors опубликованной копии
[TrackerScheme.res](https://github.com/incognico/configs/blob/master/games/cstrike/resource/TrackerScheme.res).
Это пользовательская копия схемы; компоновка адаптирована под наше приложение,
побайтовое совпадение с конкретной сборкой игры не заявляется.

| Роль | RGB / CSS |
| --- | --- |
| ControlBG | 76, 88, 68 / #4C5844 |
| WindowBG / ListBG | 62, 70, 55 / #3E4637 |
| SelectionBG | 149, 136, 49 / #958831 |
| BorderDark | 40, 46, 34 / #282E22 |
| BaseText | 216, 222, 211 / #D8DED3 |
| DimBaseText | 160, 170, 149 / #A0AA95 |
| BrightControlText | 196, 181, 80 / #C4B550 |
| BorderBright | 136, 145, 128 / #889180 |

Цвета статусов качества — дополнение приложения, а не историческая часть VGUI.

Персонаж создан встроенным imagegen; файл — `services/frontend/images/wizard.png`,
исходный запрос — `services/frontend/images/wizard-prompt.txt`. Изображение
локальное, не требует внешнего сервиса для показа.

## Проверки

`tests/application/test_dashboard.py` проверяет общие сценарии во всех трёх темах:
URL/localStorage, клавиатуру, отсутствие новых API-запросов при переключении,
сохранение пагинации, скрытие помощника и ширину 390 px.
PostgreSQL-сценарии требуют выделенной `TEST_DATABASE_URL`.
