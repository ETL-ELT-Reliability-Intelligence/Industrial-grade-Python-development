# Финальная версия приложения

Обязательный контур: мониторинг качества данных, статистические аномалии,
почасовой ML-прогноз mock_orders и предупреждения пользователя. BLOCK не
останавливает пайплайн автоматически. Инциденты, RCA и VAE не входят в релиз.

Приложение читает сохранённые результаты: каталог datasets, партии, области
проверки, историю Evaluation, запуски pipelines и результаты детекторов.
API/UI не запускает переоценку, обучение или DAG самостоятельно.

Для выбранного расчёта раздел детекторов показывает факт, ожидание, интервал,
PASS/WARN/SKIPPED/ERROR, причину пропуска/ошибки, версию и связанные аномалии.
Отсутствие записи не преобразуется в PASS. Отдельно показывается последняя
попытка обучения, число пригодных часов и недостающие периоды.

Приёмка описана в [FINALIZATION.md](../FINALIZATION.md). Она использует текущие
run_id и неизменяемые манифесты партий, проверяет реальные API и включает проверки
сбоев на Kafka/S3/PostgreSQL. Браузерные тесты проверяют три оформления, мобильную
ширину, отображение нуля, пропуски и ручное обновление.

Исторические результаты предыдущих итераций сохранены в
[отчёте от 08.11](../../reports/ulyanova/report_as_of_08.11.md). Они не заменяют
проверку текущей версии. Старое JSON-demo инцидентов изолировано от рабочего API.
